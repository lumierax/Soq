# الرفع من iPhone بملفين فقط

استخدم **Safari** وسجّل دخولك إلى GitHub. حمّل الملفين المنفصلين `NABD-Free-iOS-GitHub.zip` و`NABD-Free-import-and-build.yml` من الرسالة نفسها؛ لا تفك ضغط ZIP، ولا تستخدم قالب YML الموجود داخله.

1. أنشئ مستودعًا جديدًا **Public** باسم `nabd-free` من `github.com/new`، وفعّل **Add a README file** فقط. اترك ملفات gitignore وlicense دون إضافة. استخدم مستودعًا جديدًا لهذه النسخة حتى لا تتعارض مع استيراد النسخة السابقة.
2. افتح المستودع واختر **Add file → Upload files**، ثم **choose your files**. ارفع الملفين معًا من تطبيق «الملفات» واضغط **Commit changes**. إذا اختفت الخيارات، استخدم **طلب موقع سطح المكتب** في Safari.
3. افتح `NABD-Free-import-and-build.yml` الذي رفعته، واختر رمز القلم **Edit**. غيّر اسمه في خانة المسار إلى `.github/workflows/import-and-build.yml` ثم **Commit changes** إلى الفرع الافتراضي. افتح **Actions → Import NABD and build iOS IPA → Run workflow**.

بعد نجاح التشغيل، حمّل ملف **Artifacts** من صفحة التشغيل. الوضع الافتراضي ينتج **Nabd-iOS-unsigned-needs-signing**: ملف جهاز iPhone حقيقي يحتاج توقيع Apple قبل تثبيته. للإصدار الموقع، أضف أسرار Apple المذكورة في [دليل iOS](IOS_AR.md)، ثم فعّل `sign_ipa` واختر طريقة التصدير المناسبة عند التشغيل.

البرنامج يفك ZIP داخل خادم GitHub، ويحفظ مصادر التطبيق في المستودع، ثم يبني IPA. ملفا ZIP وYML متطابقان بواسطة SHA-256؛ رفع ZIP من إصدار مختلف يوقف التشغيل قبل فكّه. إعادة التشغيل تحفظ تعديلاتك الحالية ولا تستورد المصادر فوقها. لا تحتاج إرسال كلمة مرور أو token.

لنشر واجهة ويب مجانية باستخدام ملف `NABD-pages.yml`، اتبع [دليل النسخة المجانية](FREE_AR.md) بعد استيراد المصادر. المستودع العام يجعل الملفات مرئية؛ لا ترفع مفاتيح Binance أو شهادات Apple أو ملفات `.env` إليه.

## شكل المستودع قبل أول تشغيل

```text
README.md
NABD-Free-iOS-GitHub.zip
.github/workflows/import-and-build.yml
```

ZIP يحتوي مجلدًا واحدًا اسمه `NABD/`، ويضع البرنامج محتوياته في جذر المستودع. يستبدل README الأول الذي أنشأه GitHub بدليل المشروع ويحتفظ بنسخة منه في `.nabd-mobile-import-backup/README.md`. يتوقف عند وجود مصادر سابقة أو ملفات متعارضة؛ استخدم مستودعًا جديدًا لهذا الاستيراد.

ملفات `.github/workflows` الموجودة داخل ZIP لا تُستورد، لأن رمز Actions لا يملك صلاحية إضافتها. يبقى ملف `import-and-build.yml` الذي أنشأته أنت هو المسؤول عن البناء. لا يعمل ZIP وحده قبل نقل YML إلى المسار أعلاه. إذا كانت Actions معطلة أو الفرع محميًا ضد الكتابة، يلزم السماح بتشغيل workflow وحفظ المصادر في هذا المستودع الجديد.
