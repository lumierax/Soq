# نسخة مجانية بلا خادم للسوق

النسخة الجديدة تجلب بيانات Binance العامة وتحللها مباشرة داخل التطبيق أو المتصفح، دون مفتاح للسوق ودون استضافة مدفوعة. تعمل المتابعة والتحليلات أثناء فتح التطبيق؛ وصول Binance يعتمد على اتصالك وتوفر الخدمة في بلدك.

## نشر الواجهة من iPhone

1. أنشئ مستودعًا جديدًا **Public** باسم `nabd-free`. ارفع `NABD-Free-iOS-GitHub.zip` دون فك ضغطه وملف `NABD-Free-import-and-build.yml` المطابق، ثم شغّل الاستيراد كما في [دليل الرفع من الهاتف](PHONE_UPLOAD_AR.md). GitHub Pages مجاني للمستودعات العامة في GitHub Free. انتظر نجاح استيراد المصادر وظهور مجلد `frontend`؛ المستودع الجديد يتجنب التعارض مع استيراد النسخة السابقة.
2. ارفع ملف `NABD-pages.yml` المنفصل إلى المستودع. افتحه، اضغط القلم، وغيّر مساره إلى `.github/workflows/pages.yml` ثم احفظ إلى الفرع الافتراضي. من **Settings → Pages → Build and deployment → Source** اختر **GitHub Actions**.
3. افتح **Actions → Publish NABD to GitHub Pages → Run workflow**. بعد نجاح النشر يظهر رابط الموقع في صفحة التشغيل وفي **Settings → Pages**. افتحه في Safari؛ تستطيع إضافته إلى الشاشة الرئيسية.

إذا تعذر ظهور الخيارات في Safari، اختر **طلب موقع سطح المكتب**. عند تعديل ملفات الواجهة على فرع `main` أو `master` يُعاد النشر تلقائيًا؛ لأي اسم فرع آخر استخدم **Run workflow**.

يُنشر محتوى `frontend/dist` فقط. المستودع العام يجعل الملفات المرفوعة إليه مرئية أيضًا؛ احتفظ بمفاتيح Binance وشهادات Apple وملفات `.env` خارج ملفات المستودع. توضع أسرار توقيع IPA في **Settings → Secrets and variables → Actions** وفق [دليل iOS](IOS_AR.md).

## الويب وIPA والتداول

GitHub Pages ينشر تطبيق ويب ثابتًا؛ لا يشغّل Python ولا يوفر API لخادم التداول. إصدار IPA الجديد يستخدم البيانات العامة مباشرة أيضًا. إصدار IPA السابق الذي يعتمد على خادم يحتاج إعادة بناء بالنسخة الجديدة؛ إدخال رابط Pages في خانة API لا يحوّله إلى خادم.

بوت الفيوتشر الحقيقي يحتاج تشغيل خدمة التداول على جهازك بصورة مستمرة أو على استضافة مستمرة. يمكنك تشغيلها على حاسوبك دون اشتراك استضافة، لكنه يجب أن يبقى متصلًا ومشغّلًا لتنفيذ البوت وتنبيهات Telegram. GitHub Pages والهاتف المغلق لا يشغّلان هذه الخدمة في الخلفية.

إذا لم يكن لديك حاسوب، يوجد خيار [Oracle Always Free](https://www.oracle.com/cloud/free/faq/) لخادم افتراضي ضمن الحصص المجانية، ويحتاج بطاقة للتحقق وقد يتعذر توفيره. اختر موارد موسومة **Always Free**؛ الرصيد التجريبي لمدة 30 يومًا مختلف. توضح [الشروط](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm) أن الموارد الخاملة قد تُسترجع، ولا يوجد ضمان استمرارية. لا تحتاج ترقية مدفوعة لهذا المسار، ولم يُنشأ خادم Oracle بهذه الحزمة.
